# 3D model credits

All models are loaded via `src/features/explorer/three/GLBModel.tsx` (and
`FoxModel.tsx`), auto-normalised in size, with procedural fallbacks so the
scene never breaks if a load is slow or fails.

## fox.glb
Low-poly **Fox** from the Khronos glTF Sample Assets.
- Mesh: **PixelMannen** — CC0. Rig & animation: **@tomkranis** — CC-BY 4.0.
- https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox
